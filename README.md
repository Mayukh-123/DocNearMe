# DocNearMee
DocNearMe is a healthcare discovery platform that allows users to find verified doctors nearby and book appointments conveniently. The website includes features such as doctor listings, clinic timings, location details, and an appointment booking system. This project was created as part of a web development workshop to demonstrate practical frontend development using HTML, CSS, and JavaScript.
